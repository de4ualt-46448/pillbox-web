## Railway Deployment — pillbox-web

Deploy as one Railway service (Node) + one Railway Postgres database. The Node service serves both the Express API and the built React client. MQTT runs over the public HiveMQ broker so the deployed server and ESP32 work together on any network.

### Files to edit

1. **`server/prisma/schema.prisma`** — change `datasource db` provider from `"sqlite"` to `"postgresql"` (matches README intent; required for Railway Postgres).

2. **`server/package.json`** — move `tsx` and `prisma` from `devDependencies` to `dependencies`. The start command runs the app via `tsx` and applies migrations via the `prisma` CLI at deploy time; Railway production installs omit devDependencies, so both must be runtime deps or the container crash-loops. Leave TypeScript/`@types/*` in devDependencies (not needed at runtime — `tsx` runs TS directly).

3. **`railway.json`** — keep NIXPACKS builder and the existing flow, but make the build command robust as a single workspace-aware command sequence (root install → client build → server install → prisma generate). Start command unchanged: `cd server && npx prisma db push --skip-generate && npx tsx src/index.ts`. Healthcheck `/api/health`, restart ON_FAILURE.

4. **`.env.example`** (new, root) — single source of truth for Railway variables:
   - Required: `DATABASE_URL`, `JWT_SECRET`, `JWT_REFRESH_SECRET`
   - MQTT: `MQTT_BROKER_URL=mqtt://broker.hivemq.com:1883`
   - Optional: `CLIENT_ORIGIN`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `ELEVENLABS_API_KEY`, `NVIDIA_*`, `GROQ_API_KEY`, `OPENAI_API_KEY`
   - `NODE_ENV=production`

5. **`README.md`** — add a "Deploy to Railway" section: provision Postgres, set the variables above, deploy from the repo; note that the ESP32 firmware's broker host must be set to `broker.hivemq.com` so device + server share a public broker.

### Not changed
- `hardware-bridge` (local-only, not deployed), app logic, auth, routes, client build config, embedded aedes broker code (skipped on Railway because `MQTT_BROKER_URL` is set).

### After edits (manual steps on Railway)
Push to GitHub → New Project from repo → add PostgreSQL service → set env vars (`DATABASE_URL` referencing Postgres, `JWT_SECRET`, `JWT_REFRESH_SECRET`, `MQTT_BROKER_URL`, `NODE_ENV=production`) → deploy → point ESP32 firmware broker to `broker.hivemq.com`.
