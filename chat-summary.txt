REQUEST 2: Fix - .bat opens and closes after 5 seconds
---------------------------------------------------------------

Problem: The .bat window was closing too quickly.

Root cause: npm workspaces hoist dependencies to root node_modules,
so `npx tsc` in subdirectories was routing through the root workspace
and not finding the right tsconfig.

Fix: Updated dev.bat to use root tsc directly:
  .\node_modules\.bin\tsc --project client/tsconfig.json --noEmit
  .\node_modules\.bin\tsc --project server/tsconfig.json --noEmit
  .\node_modules\.bin\tsc --project hardware-bridge/tsconfig.json --noEmit

Added `pause >nul` at the end so the window always stays open.
